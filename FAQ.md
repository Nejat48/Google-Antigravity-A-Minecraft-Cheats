# Frequently Asked Questions (FAQ)

## General Questions

### Q: What is this mod?
**A:** This is an Antigravity cheat mod for Minecraft that provides various gameplay modifications.

### Q: Is this mod safe to use?
**A:** The mod itself is a JAR file for Minecraft. However:
- Only download from official sources
- Using cheats may get you banned from servers
- Use at your own risk

### Q: Can I use this on multiplayer servers?
**A:** Technically yes, but:
- Most servers prohibit cheating
- You will likely get banned if caught
- It's against most servers' terms of service
- We recommend using only in single-player

## Installation Questions

### Q: How do I install this mod?
**A:** See the detailed instructions in README.md. Basic steps:
1. Download the JAR file
2. Place it in your Minecraft mods folder
3. Launch Minecraft with a mod loader

### Q: I'm on mobile, can I use this?
**A:** No, this is for Minecraft Java Edition on PC (Windows, macOS, or Linux). Minecraft Pocket Edition (mobile) cannot use Java mods.

### Q: What Minecraft version does this work with?
**A:** Check the mod's compatibility information. If not specified, you may need to test or ask in an issue.

### Q: Do I need Forge or Fabric?
**A:** You need a mod loader like Forge or Fabric. Check which one this mod requires.

## Troubleshooting

### Q: The mod isn't working, can you access my computer to fix it?
**A:** **NO! Never give anyone remote access to your computer!** This is extremely dangerous. Instead:
- Read the installation guide carefully
- Check error logs in the Minecraft folder
- Create a GitHub issue with details about your problem

### Q: I'm getting an error when I launch Minecraft
**A:** Common solutions:
- Make sure you have the correct Minecraft version
- Verify you have the right mod loader installed
- Check for conflicts with other mods
- Look at the error message for clues
- Create a GitHub issue with the full error log

### Q: Where can I find error logs?
**A:** Minecraft logs are typically found in:
- Windows: `%APPDATA%\.minecraft\logs\latest.log`
- macOS: `~/Library/Application Support/minecraft/logs/latest.log`
- Linux: `~/.minecraft/logs/latest.log`
