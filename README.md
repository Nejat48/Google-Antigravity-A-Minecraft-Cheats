## What is this project?

This repository contains a Minecraft cheat mod (Antigravity Cheats) packaged as a JAR file. 

## How to Use

### Requirements
- Minecraft Java Edition
- A compatible mod loader (Forge, Fabric, etc.)
- Java Runtime Environment

### Installation

1. **Download the JAR file**: Download `Antigravity Cheats.jar` from this repository
2. **Locate your Minecraft mods folder**:
   - Windows: `%APPDATA%\.minecraft\mods`
   - macOS: `~/Library/Application Support/minecraft/mods`
   - Linux: `~/.minecraft/mods`
3. **Copy the JAR file**: Place the downloaded JAR file into your mods folder
4. **Launch Minecraft**: Start Minecraft with your mod loader

### Using the Cheats

Once installed, the antigravity cheats will be available in your Minecraft game. Refer to in-game controls or documentation for specific features.
