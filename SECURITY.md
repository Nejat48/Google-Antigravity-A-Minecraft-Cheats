# Security Policy

## 🚨 CRITICAL SECURITY WARNINGS

### NEVER Give Remote Access to Your Computer

If someone asks you for remote access to your computer, **DO NOT DO IT**. This is true whether:
- You're on mobile or desktop
- They claim they're from tech support
- They promise to "help" with installation
- They say it's "necessary" for the mod to work

**Legitimate software does NOT require remote access to your computer.**

### Why Remote Access is Dangerous

Giving someone remote access to your computer allows them to:
- View all your files and personal information
- Install malware or spyware
- Steal passwords and login credentials
- Access your bank accounts and financial information
- Use your computer for illegal activities
- Delete or encrypt your files (ransomware)

### Safe Ways to Get Help

If you need help with this mod, here are SAFE ways to get assistance:

1. **Read the documentation**: Check README.md and other documentation files
2. **Search existing issues**: Look through GitHub Issues to see if others had the same problem
3. **Create a GitHub Issue**: Describe your problem in detail in a new issue
4. **Share screenshots**: Take screenshots of error messages (not remote access)
5. **Copy error logs**: Paste error text into your issue (not remote access)

### What to Do Instead

If you're having trouble installing or using this mod:

1. **From your mobile device**: 
   - Wait until you're on your computer
   - Follow the installation instructions in README.md
   - If you get stuck, create a detailed GitHub issue

2. **From your computer**:
   - Follow the step-by-step instructions in README.md
   - Check that you have all requirements installed
   - If something doesn't work, copy the error message and create an issue

### Reporting Security Vulnerabilities

If you discover a security vulnerability in this mod, please report it by:
1. Creating a private security advisory on GitHub
2. Or emailing the repository maintainer directly (if contact info is provided)

**Do NOT** post security vulnerabilities in public issues.

## Best Practices

- Keep your antivirus software updated
- Download files only from trusted sources
- Be suspicious of unsolicited help offers
- Never share passwords or personal information
- Use strong, unique passwords for each service

---

**Stay safe online! If something seems suspicious, it probably is.**
