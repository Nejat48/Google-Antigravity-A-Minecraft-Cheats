# Contributing Guide

Thank you for your interest in contributing to this project!

## How to Report Issues

When creating an issue on GitHub, please follow these guidelines:

### For Bug Reports

Include the following information:
- **Description**: What is the bug? What did you expect to happen?
- **Steps to Reproduce**: Detailed steps to recreate the issue
- **Minecraft Version**: Which version of Minecraft are you using?
- **Mod Loader**: Are you using Forge, Fabric, or another mod loader? Which version?
- **Other Mods**: List any other mods you have installed
- **Error Messages**: Copy and paste any error messages or logs
- **Screenshots**: If applicable, include screenshots showing the problem

### For Feature Requests

Include:
- **Description**: What feature would you like to see?
- **Use Case**: Why would this feature be useful?
- **Proposed Implementation**: If you have ideas on how it could work

### For Questions

- **Check existing issues first**: Your question might already be answered
- **Be specific**: Clearly describe what you need help with
- **Include context**: What were you trying to do when you got stuck?

## ⚠️ What NOT to Do

### DO NOT:
- Ask for remote access to computers
- Share personal information (passwords, email, addresses)
- Post spam or unrelated content
- Be rude or disrespectful to others
- Post the same question multiple times

## How to Contribute Code

If you want to contribute code to this project:

1. **Fork the repository** to your GitHub account
2. **Clone your fork** to your local machine
3. **Create a new branch** for your changes
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make your changes** and test them thoroughly
5. **Commit your changes** with clear, descriptive commit messages
6. **Push to your fork** 
   ```bash
   git push origin feature/your-feature-name
   ```
7. **Create a Pull Request** from your fork to this repository

### Code Guidelines

- Write clear, readable code
- Comment complex sections
- Test your changes before submitting
- Follow existing code style and conventions

## Getting Help

If you need help contributing:
- Check the README.md for project information
- Look at existing pull requests for examples
- Ask questions in a new issue (tagged as "question")

## Code of Conduct

Be respectful and constructive. We're all here to learn and improve the project together.
